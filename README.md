# Львівський обласний госпіталь — React-сайт

## Запуск

Потрібен Node.js 20 або новіший. Установіть пакети командою `npm install`, а потім зберіть сайт командою `npm run build`.

Перед запуском задайте власний пароль адміністратора (щонайменше 12 символів). У macOS або Linux це можна зробити без запису пароля в історію команд:

```sh
read -s 'ADMIN_PASSWORD?Пароль адміністратора: '
export ADMIN_PASSWORD
npm start
```

Відкрийте `http://localhost:3001`, а панель керування — `http://localhost:3001/admin`. Пароль не зберігається в проєкті; його потрібно задавати для кожного запуску сервера. Без пароля вхід вимкнений. Вихід із термінала зупиняє сервер.

Для розробки задайте `ADMIN_PASSWORD` так само, як вище, і виконайте `npm run dev`. Ця команда запускає сервер даних на порту 3001 і Vite; відкрийте адресу Local, яку виведе Vite. Для повторного запуску спочатку зупиніть попередній процес клавішами Ctrl+C.

## Дані

Публічний вміст імпортовано зі старого сайту у `data/content.json`: сторінки, новини, профілі лікарів, команди відділень, проєкти реконструкції та платні послуги. Сторінки та новини редагуються через адмінпанель. Новини можна додавати та редагувати через текстові поля і завантажувати фото до 1 МБ. Текст сторінок змінюється у полях зі збереженням оформлення. У розділі «Платні послуги» можна додавати, редагувати і видаляти послуги та їхні ціни окремо для госпіталю і кардіоцентру.

Фото й документи (PDF тощо) зберігаються локально в папці `media/wp-content/uploads/` і відкриваються за тими самими адресами, що й на старому сайті. Сайт не залежить від старого WordPress, тож папку `media/` треба переносити на сервер разом із `data/`.

Папка `media/` (понад 450 МБ, окремі файли більші за 100 МБ) не зберігається в git. Після клонування репозиторію заповніть її командою `python3 scripts/import.py`, поки старий сайт працює. **До вимкнення старого WordPress обов'язково збережіть копію `media/`** (на сервері, в архіві чи сховищі файлів): після вимкнення відновити ці файли імпортом уже не вдасться.

### Повторний імпорт

Потрібен Python 3 із пакетом `lxml` (`pip install lxml`). Запускайте з кореня проєкту:

```sh
python3 scripts/import.py              # сторінки, новини, лікарі, команди, проєкти, фото й документи
python3 scripts/import.py --services   # те саме + платні послуги з оригіналу
python3 scripts/import.py --no-media   # без завантаження файлів
```

Перед записом скрипт сам зберігає резервну копію `data/content.backup-<дата>.json`. Імпорт перезаписує сторінки, новини й лікарів даними зі старого сайту, тож правки цих розділів з адмінпанелі буде втрачено. Новини, створені в адмінпанелі, зберігаються. Платні послуги без `--services` не змінюються. Уже завантажені файли повторно не завантажуються.

Ця версія призначена для локальної розробки. Перед публікацією потрібні сервер із постійним сховищем для `data/content.json`, HTTPS, налаштування резервного копіювання та перевірка безпеки. Сесії зберігаються в пам'яті та припиняються після перезапуску сервера. Імпортовані сторінки зі складними блоками старого WordPress можуть потребувати ручного доопрацювання.
